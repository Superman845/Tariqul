# TypingClub Clone - Complete Typing Tutor

A fully-featured typing tutor application that clones TypingClub.com with all modern features implemented using pure HTML, CSS, and JavaScript.

## ✨ Features Overview

### 🎯 Core Typing Features
- **Real-time typing feedback** with color-coded characters (green=correct, red=incorrect, yellow=current)
- **Automatic horizontal scrolling** keeps current character visible
- **Live statistics tracking** (WPM, accuracy, characters, errors, time)
- **Complete lesson system** with 20+ built-in lessons across multiple categories

### ⌨️ Virtual Keyboard
- **Full QWERTY keyboard** with all standard keys including Shift, Tab, CapsLock
- **Clickable keys** that trigger actual typing behavior
- **Real-time key highlighting** for next required key
- **Visual keypress feedback** with animations
- **Multiple keyboard themes** (Default, Blue, Green, Purple)
- **Shift combination support** for uppercase letters and symbols

### 👋 Hand & Finger Guide
- **Visual hand representation** with animated fingers
- **Color-coded finger mapping** for each key
- **Finger animation** showing which finger to use for next key
- **Resting position** with smooth return animations
- **Toggle on/off** via settings

### 📊 Performance Analytics
- **Live WPM calculation** with history tracking
- **Real-time accuracy percentage**
- **Comprehensive lesson summaries** with charts
- **Mistake analysis** showing most difficult characters
- **Progress charts** using Chart.js for visual feedback
- **Historical performance tracking** per lesson

### 🎓 Complete Lesson System
- **Built-in lesson categories:**
  - Beginner (Home row basics)
  - Home Row mastery
  - Top Row practice
  - Bottom Row practice
  - Numbers & Symbols
  - Advanced typing
- **Custom lesson creation** with full text editor
- **Lesson progress tracking** with completion status
- **Reset functionality** for starting fresh

### 👤 Profile Management
- **Multiple user profiles** with separate progress tracking
- **Profile switching** with data isolation
- **Custom avatars** with initials display
- **Profile creation/deletion** with confirmation dialogs
- **Data persistence** using localStorage

### 🏆 Achievement System
- **6 unique achievements** to unlock:
  - 🎯 100% Accuracy
  - ⚡ Speed Demon (50 WPM)
  - 📚 Dedicated Learner (5 lessons)
  - 💎 Perfectionist (0 mistakes)
  - 🏃 Fast Fingers (70 WPM)
  - 🔥 Consistent Typer (10 lessons)
- **Achievement notifications** with smooth animations
- **Progress tracking** per profile

### ⚙️ Comprehensive Settings
- **Display customization:**
  - Font size adjustment (12-24px)
  - Zoom control (80%-150%)
  - 4 themes (Light, Dark, Night, Colorful)
- **Keyboard options:**
  - Show/hide virtual keyboard
  - Next-key highlighting toggle
  - Multiple keyboard themes
- **Guidance features:**
  - Finger guide toggle
  - Ghost typing mode
- **Audio & feedback:**
  - Typewriter sound effects

### 👻 Ghost Typing Mode
- **Automated typing demonstration** showing finger movements
- **Visual key highlighting** during ghost typing
- **Lesson preview** functionality

### 🎵 Audio & Haptic Feedback
- **Typewriter sounds** for correct keystrokes

## 🚀 Getting Started

1. Open `index.html` in any modern web browser
2. Click "Lessons" to select a lesson
3. Choose from beginner to advanced lessons
4. Click "Start Lesson" to begin typing
5. Follow the on-screen keyboard and finger guides

## 🎯 Usage Tips

- **For beginners:** Start with home row lessons and use the finger guide
- **For practice:** Enable ghost typing mode to see proper technique
- **For speed:** Use advanced lessons and track your WPM progress
- **For customization:** Explore settings for themes and preferences
- **For motivation:** Try to unlock all achievements
